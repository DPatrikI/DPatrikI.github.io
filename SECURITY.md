# Security policy

Do not publish credentials, private recordings, proprietary material, or sensitive logs in an issue.

For a vulnerability in this website, use GitHub private vulnerability reporting when available or email `doczy.patrik410@gmail.com`. Include the affected URL or commit, reproducible steps, and potential impact. No response-time guarantee is offered.

For a VolEq vulnerability, follow the current [VolEq security policy](https://github.com/DPatrikI/voleq-community/security/policy). Do not file a public issue for a problem that could expose captured audio, bypass permissions, create persistent feedback, or affect system integrity.
