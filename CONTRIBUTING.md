# Contributing

Focused fixes to accessibility, factual accuracy, or site reliability are welcome.

1. Open an issue before proposing a substantial design or content change.
2. Create a focused branch and keep unrelated changes out of the pull request.
3. Run `npm ci`, `npm run verify`, and `npm audit`.
4. Do not add tracking, remote fonts, private material, secrets, unsupported product claims, or modified VolEq branding.
5. Add a `Signed-off-by` line to commits to certify the [Developer Certificate of Origin](https://developercertificate.org/).

Content that describes VolEq must be checked against the current public repository and latest published release.
